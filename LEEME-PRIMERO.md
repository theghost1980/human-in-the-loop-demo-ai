# Léeme primero

Archivos de este paquete y qué hacer con cada uno:

| Archivo | Para qué | ¿Va al repo público? |
|---|---|---|
| `CLAUDE.local.md` | Reglas de trabajo para Claude en tu PC | ❌ No (está en `.gitignore`) |
| `docs/PLAN.md` | Plan completo por fases | ✅ Sí |
| `docs/ROADMAP.md` | Checklist de avance | ✅ Sí |
| `docs/dev-log.md` | Diario de desarrollo | ✅ Sí |
| `README.md` | Portada del repo con la nota de licencia | ✅ Sí |
| `.gitignore` | Excluye secretos, `CLAUDE.local.md` y `private/` | ✅ Sí |
| `LEEME-PRIMERO.md` | Este archivo | ❌ Bórralo cuando termines |

## Pasos

1. Crea el repo `hexis-ops` en GitHub (público) y clónalo en tu PC.
2. Copia estos archivos dentro.
3. **Licencia:** descarga el texto oficial de *PolyForm Noncommercial 1.0.0* desde polyformproject.org y guárdalo como `LICENSE` en la raíz. No lo escribas a mano.
4. Abre Claude en la carpeta y pídele: *"Lee CLAUDE.local.md y docs/PLAN.md. Empezamos la Fase 0, primer punto del roadmap."*
5. Tus hooks y configuración local de Claude siguen funcionando igual. Este paquete no trae hooks ni settings.

## Nota sobre `CLAUDE.local.md`

Es personal y no se sube. Si algún día quieres que las reglas queden visibles en el repo (por ejemplo, para enseñar cómo trabajas con IA), copia las partes generales a un `CLAUDE.md` público.
