# Hexis Ops

**Human-in-the-loop AI agents for business operations.**

An agent reads business documents (supplier emails, leads, invoices, support tickets), proposes actions with a confidence level, auto-applies what is safe and routes exceptions to a human reviewer. Every decision is audited, every model call is costed, and agent quality is measured with evals.
